## How the site is built

It is a single static page with no frameworks and no build step.

- `index.html` contains all the HTML, CSS and a small amount of JavaScript.
- `profile.jpg` is the portrait shown in the hero section.
- It supports light and dark mode, adapts to mobile screens, and respects reduced-motion settings.

## Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/DTounda/DTounda.github.io.git
   ```
2. Open `index.html` in your browser.

## Deployment

The site is deployed with GitHub Pages from the `main` branch. Any change pushed to `index.html` goes live within a minute or two.
